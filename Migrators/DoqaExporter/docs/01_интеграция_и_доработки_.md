# Integration changes

This chapter describes adaptations made when integrating the client-provided DoqaExporter
into the [testit-tms/migrators](https://github.com/testit-tms/migrators) repository.

## Build and project layout

| Change | Reason |
|--------|--------|
| Target framework `net10.0` → `net8.0` | All migrators and CI use .NET 8 |
| ProjectReference `project-importer/Models` → `Migrators/Models` | Shared models live in this repo |
| Added `PublishSingleFile` / `SelfContained` | Required for release publish artifacts |
| Added `Microsoft.Extensions.Configuration.Binder` | Needed for `GetSection("doqa").Bind(...)` |
| Removed unused `Microsoft.Extensions.Http.Polly` | Retry was documented but never wired |

## Dependency injection

Local `JsonWriter.WriteService` expects `(ILogger, IConfiguration)` and reads `resultPath` from config.

The original code used `new WriteService(resultPath)`, which does not compile against this repo.

**Fix:** register `IConfiguration` and `IWriteService` → `WriteService` via DI (same pattern as Qase/PractiTest).

## Configuration and docs

- Added sample `doqa.config.json` (copied to output)
- Aligned `Readme.md` with other exporters (Download, How to use, Contributing, License)
- Listed DOQA in the root `README.md`
- Logs and user-facing strings switched to English

## Bug fixes

- Checklist display name truncation used a different string for length vs content when title was empty — fixed by building one `name` string and truncating it to 255 characters

## Tests and CI

- Added `DoqaExporterTests` (NUnit + NSubstitute): `ExportServiceTests`, `HtmlProcessorTests`
- Hooked into `validate-tests.yml`
- Added `check-release-doqa.yml` and `doqa_build` job in `release.yaml`

## Known limitations (unchanged)

- DOQA `tagIds` are not resolved to tag names
- Checklists are placed into a single `Checklists` section (folder tree not preserved)
- Images from checklist item titles and checklist file attachments are not saved
- DOQA HTTP API is unofficial (discovered via network inspection); no exponential-backoff retry yet
- Rate limiting is a fixed `Task.Delay(200)` between items
